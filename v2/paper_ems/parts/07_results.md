## 6.2 Validation of the BBS statistics

The pipeline parsed {{ f"{BBS['n_rows']:,}" }} district rows from the 14 yearbook editions (28 edition–crop-year tables). All accepted rows satisfy the three identities with a maximum relative discrepancy of {{ f(100 * BBS['max_e'], 2) }} %. Of the parsed rows, {{ BBS['n_fail'] }} failed, all in the 2012-13 columns of the 2013 edition and all on the yield identity alone ($E_Y$ between {{ f(100 * BBS['fail_ey_min'], 1) }} % and {{ f(100 * BBS['fail_ey_max'], 1) }} %, with area and production consistent), which indicates misprinted maund-per-acre values; the same district-years are printed consistently in the 2014 edition, which is used. In {{ BBS['n_complete'] }} of the 28 tables all 64 district rows were parsed; in the remaining four (the 2015 and 2018 editions, where part of the table did not parse) the same crop years are complete in another edition. Of the {{ BBS['n_complete'] }} complete tables, {{ BBS['n_nat_complete'] }} print a national total, and the sum of district production equals it to within {{ "0.001" if BBS['max_gap_pct'] < 0.001 else f(BBS['max_gap_pct'], 3) }} %. The other {{ w(BBS['n_complete'] - BBS['n_nat_complete']) }} (both tables of the {{ BBS['no_nat_editions'] }} editions) print no national row. They cover {{ w(BBS['no_nat_years']) }} crop years, {{ w(BBS['no_nat_covered']) }} of which have a national total in another edition; for the remaining {{ w(BBS['no_nat_years'] - BBS['no_nat_covered']) }} the district sums agree with the totals quoted in the yearbook text: {{ f"{NATSUM['2010-11']:,.0f}" }} t against "186.17 lac metric tons" for 2010-11 (2012 edition), and {{ f"{NATSUM['2021-22']:,.0f}" }} t against "201,85,945 metric tons" for 2021-22 (2022 edition). Crop years {{ ACC['two_first'] }} to {{ ACC['two_last'] }} are printed in two editions, giving {{ ACC['possible_pairs'] }} district-year pairs. Compared on area and yield, {{ ACC['diff'] }} of the {{ ACC['pairs'] }} pairs differ, each by at most {{ ACC['max_diff'] }} ha of area, consistent with rounding (Table 8; Appendix Table C.1 traces every row from parsing to the panel).

The region-structured editions reconcile with present-day districts. ## 6.4 Deliberate failure tests

All {{ w(EVS['corrupt']) }} failure tests passed ({{ EVS['corrupt_pass'] }} of {{ EVS['corrupt'] }}; Table 10). The six tests on the Bronze inputs stopped the Silver and Gold build (s03) with a diagnostic giving the check identifier, the file and column and, where the error concerned specific records, the district and year. Three of the four tests on the parsed yearbook rows were caught by checks that use the redundancy of the yearbooks. The fourth, a row dropped from a crop year printed in only one edition, leaves an incomplete table, to which the national-total check does not apply, and no second edition to compare with; it was caught by the completeness check of the build. The transposed digits broke the identity between area, yield and production, so the row was excluded, and the district sum of the table no longer matched the printed national total, which stopped the validation step with a diagnostic naming the edition and crop year. The exchanged lines satisfied every identity and the national total, as expected, but disagreed with the 2020 and 2022 editions, which print the same crop years; the comparison between editions stopped the run and named the four district-years affected. The dropped row left a district-year without a BBS value, which stopped the build with a diagnostic naming Khulna 2025. The misread yield broke two identities, so the row was excluded, and it also disagreed with the other edition, by 38 t/ha, which the diagnostic reports as the largest yield difference. The baseline run completed, passed every validation check and reproduced the real BBS table and Gold panel with identical SHA-256 checksums (result: {{ EVS['baseline'] }}).

The tests also exposed defects during development, all corrected before the results reported here were produced. The wrong-type test at first ran to completion: the CSV reader converted the text "n/a" to a missing value, which the range checks then skipped. Numeric columns are now read strictly and the BBS values must be present ([MISSING]), and the missing-value test was added to cover this case. In the Earth Engine extraction, Sentinel-1 flash flood fractions were found to be missing for harvest year 2015, the only Sentinel-1 year processed as a single-band image, because Earth Engine names the output of a single-band reduction after the reducer rather than the band. Outputs are now named explicitly, and the completeness test of Section 4.5 rejects any extract that lacks an expected variable; recomputing harvest year 2016 through the single-band path reproduced the stored values to within 10⁻¹⁶. Finally, the first fresh-setup test found two sources of spurious differences: the manifest recorded file modification times, which change when files are copied, and district areas differed in the fifteenth significant digit between versions of the geometry libraries. Extraction dates are now recorded when each extract is computed, and areas are rounded to 0.001 km². A later fresh-setup run showed that the manuscript build failed in a clean copy when no failure-test results existed yet; it now marks the manuscript as a draft instead.

## 6.5 Reproducibility

Repeated builds on the same installation produced byte-identical analysis outputs and the same Gold panel checksum. The fresh-setup test passed in both environments (Table 11). In environment A the installer chose versions different from the lock file for {{ len(fs_env('A', 'packages_differing_from_lock', [])) }} of {{ fs_env('A', 'packages') }} packages, among them the geometry libraries shapely and pyproj; in environment B {{ 'every package matched the lock file' if not fs_env('B', 'packages_differing_from_lock', []) else str(len(fs_env('B', 'packages_differing_from_lock', []))) + ' packages differed' }}. In both environments the pipeline completed, the validation report raised no failures, the {{ w(EVS['corrupt']) }} failure tests and the baseline passed, and each of the {{ EVS['files'] }} files fell into one class of Table 6. Of the {{ EVS['generated'] }} generated outputs, {{ EVS['identical'] }} were byte-identical, {{ EVS['same'] }} had the same content in a file that stores write times or folder paths (the Gold database, the failure-test logs and two Word files), and {{ EVS['runtime'] }} differed only in measured run times (the timing record and the manuscript in its Markdown and Word versions); the other {{ EVS['kept'] }} files are kept in the repository rather than generated. ## 6.7 Consistency of the derived flood variables

The two flood sources agree strongly over their overlap period (Table 13, Fig. 3). For monsoon flooding (harvest years {{ R['flood_overlap_monsoon']['years'].replace('-', '–') }}, {{ R['flood_overlap_monsoon']['n'] }} district-years), the pooled correlation between JRC and Sentinel-1 district fractions is {{ f(R['flood_overlap_monsoon']['pearson_r'], 2) }} (95 % cluster-bootstrap interval {{ f(R['flood_overlap_monsoon']['pearson_r_ci'][0], 2) }}–{{ f(R['flood_overlap_monsoon']['pearson_r_ci'][1], 2) }}), and the mean bias is {{ f(100 * R['flood_overlap_monsoon']['bias'], 1) }} percentage points of district area. The agreement is driven mainly by differences between districts (correlation of district means {{ f(R['flood_overlap_monsoon']['district_mean_r'], 2) }}); agreement on year-to-year variation within districts is moderate ({{ f(R['flood_overlap_monsoon']['within_district_r'], 2) }}). For flash flooding (harvest years {{ R['flood_overlap_flash']['years'].replace('-', '–') }}, {{ R['flood_overlap_flash']['n'] }} district-years), the pooled correlation is lower ({{ f(R['flood_overlap_flash']['pearson_r'], 2) }}, interval {{ f(R['flood_overlap_flash']['pearson_r_ci'][0], 2) }}–{{ f(R['flood_overlap_flash']['pearson_r_ci'][1], 2) }}) and less certain, as expected for a short April–May window in which a single cloud-free Landsat scene can decide whether flooding is observed, but the within-district agreement is higher ({{ f(R['flood_overlap_flash']['within_district_r'], 2) }}), reflecting large, shared year-to-year signals such as the 2017 flood.

## 6.8 The integrated panel and an example application

The Gold panel holds {{ R['n_panel'] }} district-years with BBS area, yield and production, and each covariate for its source period (Table 3; descriptive statistics in Appendix Table D.1). District Boro yield averaged {{ f(R['yield_mean']) }} t/ha of husked rice (SD {{ f(R['yield_sd']) }}), and national yield, computed from the district totals, rose from {{ f(R['national_yield']['2011']) }} t/ha in 2011 to {{ f(R['national_yield']['2025']) }} t/ha in 2025, matching the national yields printed by BBS to within {{ f(R['national_yield_check_max_abs_diff'], 4) }} t/ha.

The example vulnerability index computed from the Gold tables (Appendix B) ranks highest the north-eastern districts in and near the haor basin, the coastal districts Patuakhali and Barguna, and the western districts Chapai Nawabganj and Meherpur.
